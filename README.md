# Kendra Bexly Website

Initial public launch shell for KendraBexly.com.

## Deployment
Cloudflare Workers deploy command: `npx wrangler deploy`

No build command is required for this initial static version.

## Important
The newsletter form, X feed, client request portal, admin dashboard, client records, screening workflow, email automations, and ID handling are placeholders until their secure backend services are connected. Do not collect sensitive client data through this public shell.
